# IMPORTANT: Add Your Resume PDF

Please add your resume PDF file to this location:

**Path:** `public/resume.pdf`

The "Download Resume" button in the hero section is configured to download this file.

## How to Add:

1. Export your resume as a PDF
2. Name it `resume.pdf`
3. Place it in the `public` folder of your project
4. The download button will automatically work
